## Requirements

To run this project, you will need:
- Python 3.x
- Required Python libraries. A `requirements.txt` file will be provided for easy installation.

## Infer

To set up and run the project, follow these steps:

1.  **Clone the repository:**
    ```bash
    git clone 
    ```

2.  **Navigate to the project directory:**
    ```bash
    cd Zalo-OA
    ```

3.  **Install dependencies:**
    ```bash
    pip install -r requirements.txt
    ```
    Install ZaloSession Folder

5.  **Set up your API key:**
    Create a file named `key.env` in the project root and add your OpenRouter API key:
    ```
    GEMINI_API_KEY=your_gemini_api_key_here
    ```
    Replace `your_gemini_api_key_here` with your actual API key.

6.  **Run the Flask application:**
    ```bash
    python CTA_post_main.py
    python Add_Link_Input_Post_OA.py
    python Scheduler.py
    or using start.bat instead

    ```
